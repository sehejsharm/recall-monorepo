# Internationalization

**Status: scaffold in place, English-only shipping. Which languages to add is
your call — see "Open decision" below.**

`lib/i18n.ts` is a dependency-free translation layer. It was written by hand
rather than pulling in next-intl / react-i18next because that's a vendor and
bundle-size decision, and the whole layer is ~40 lines.

## How it works

```ts
import { t } from "@/lib/i18n";

t("footer.privacy");                        // → "Privacy"
t("search.placeholder", { count: 112 });    // → "Search 112 topics…"
```

- `en` is both the source of truth and the fallback, so a missing translation
  renders English, never a raw key.
- Keys are dot-namespaced by surface (`nav.*`, `footer.*`, `search.*`).
- Interpolation uses `{named}` placeholders. **Never** build sentences by
  concatenation — word order differs across languages.
- `MessageKey` is derived from the catalog, so a typo'd key is a type error.

## Adding a language

1. Add the locale to `SUPPORTED_LOCALES`.
2. Add a catalog: `const hi: Partial<Record<MessageKey, string>> = { ... }`
   and register it in `catalogs`. Partial is fine — gaps fall back to English.
3. Call `setLocale(detectLocale())` from a client entry point (not wired yet;
   locale is fixed to `en` until a second language exists).

## What's done vs. remaining

- **Done**: the layer, the `en` catalog, and the shared chrome (LegalFooter)
  migrated as a worked example.
- **Remaining**: per-screen strings are still inline English. Migration is
  purely mechanical (`"Text"` → `t("key")` + add the key). Left as follow-up
  deliberately so it lands in small reviewable slices instead of one
  unreviewable 20-file diff.

## Open decision — which languages?

Hindi is the obvious first for UPSC/SSC. Beyond that it depends on target
audience (Tamil / Telugu / Bengali / Marathi for state exams). **Content
translation is a much bigger cost than UI translation**: the app ships ~11k
questions and ~900 notes, and a half-translated app (Hindi buttons, English
questions) may be worse than English-only. Decide UI-only vs. UI+content
before committing.
